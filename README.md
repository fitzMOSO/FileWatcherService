# Installation Guide in CMD
>
> **Note:** Run Command Prompt as **Administrator**.

1. Open Command Prompt and navigate to the .NET Framework directory:

```cmd
cd "C:\Windows\Microsoft.NET\Framework\v4.0.30319"

InstallUtil.exe C:[your\file\path]FileWatcherService\bin\Debug\FileWatcherService.exe

```

2. Win + R

3. Search: services.msc

4. Find the service named **FileWatcherService**.

5. Right-click on it and select **Start**.

6. The service should now be running. You can check the status in the Services window.

7. To stop the service, right-click on it again and select **Stop**.

8. To uninstall the service, run the following command in Command Prompt:

```cmd

cd "C:\Windows\Microsoft.NET\Framework\v4.0.30319"

InstallUtil.exe /u C:[your\file\path]FileWatcherService\bin\Debug\FileWatcherService.exe
```

9. The service should now be uninstalled. You can check the status in the Services window.

## Viewing Logs

1. Open the **Event Viewer** by searching for it in the Start menu.

2. In the Event Viewer, navigate to **Windows Logs** > **Application**.

3. Look for entries with the source **FileWatcherService**. These entries will contain the logs generated by the service.

4. You can filter the logs by clicking on **Filter Current Log** in the right pane and selecting **FileWatcherService** as the source.

5. You can also export the logs by right-clicking on the log and selecting **Save All Events As**. Choose a location to save the log file.
